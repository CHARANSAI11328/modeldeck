# Skill Registry

Initial package version: 1.0.0

| Skill | Responsibility | Typical trigger |
|---|---|---|
| skill-architect | Skill creation and maintenance | Create, audit, test, or improve a skill |
| creative-orchestrator | Coordinates design workflow | New website, landing page, major redesign |
| creative-director | Visual concept and art direction | New brand-led visual direction |
| ui-ux-master | UX, IA, navigation, usability | User flows, interface structure, usability |
| landing-page-architect | Conversion-focused page narrative | Marketing or campaign landing page |
| design-systems | Tokens, typography, components | Design system or visual consistency |
| motion-interaction | Motion and interactions | Animation, scroll effects, interaction polish |
| responsive-design | Responsive layouts | Mobile/tablet/desktop implementation or audit |
| visual-qa | Browser visual and functional inspection | Post-build QA or visual defect audit |
| visual-research | Design references and trend research | Research, references, current design patterns |
| asset-art-director | Image and asset strategy | Imagery, illustration, icon, media direction |
| anti-generic-design | Originality and anti-template review | Generic or repetitive AI-looking design |
| accessibility-usability | Inclusive and accessible UX | Accessibility design, audit, remediation |
| design-to-code | Design fidelity and frontend implementation | Implement or match an approved design |
