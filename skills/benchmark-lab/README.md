# Benchmark Laboratory

Compare a control build (without this library) against an experimental build (with the relevant skills).

## Fair-test rules
- Use the same model/version, project brief, content, assets, environment, dependencies, and time budget where possible.
- Use separate clean project copies or branches.
- Do not let the control run access the new skills.
- Do not give the experimental run hidden extra requirements.
- Record model, date, prompt, elapsed time, tool access, and any deviations.
- Capture actual screenshots at the same viewport sizes.
- Run the same functional, accessibility, and performance checks.
- Have reviewers score anonymized outputs where practical.
- Repeat if results are highly dependent on one run.

## Suggested projects
1. Technology/SaaS product landing page.
2. Luxury/e-commerce brand landing page.
3. Creative agency landing page.

Use the briefs in `briefs/` and rubric in `resources/scorecard.md`.

## Interpretation
A single three-project comparison is useful but not statistically conclusive. Report project-level results and patterns; do not claim universal improvement from a small sample.
