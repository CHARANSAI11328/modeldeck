# Landing Page Benchmark Scorecard (100 points)

Score each criterion from 0–5, then multiply by its weight / 5. Score only observed evidence.

| Criterion | Weight | Evidence to inspect |
|---|---:|---|
| Visual quality | 20 | Hierarchy, typography, composition, spacing, color, imagery, polish |
| UI/UX | 15 | Clarity, navigation, flow, CTA, interaction states, usability |
| Originality | 15 | Project-specific concept, differentiation, avoidance of generic patterns |
| Responsive quality | 15 | Mobile/tablet/desktop composition, overflow, readability, touch behavior |
| Implementation quality | 15 | Code structure, real functionality, maintainability, errors, build/test health |
| Accessibility | 10 | Semantics, keyboard, focus, contrast, labels, reduced motion |
| Performance | 10 | Loading behavior, asset optimization, layout shift, responsiveness, audit evidence |
| **Total** | **100** | |

## Rating anchors
- 0: Missing, broken, or harmful.
- 1: Major deficiencies; core expectations mostly unmet.
- 2: Below standard; multiple notable defects.
- 3: Competent; meets baseline with some issues.
- 4: Strong; polished with minor issues.
- 5: Excellent; consistently high quality with evidence.

## Fairness
Do not infer performance or accessibility from appearance alone. Use measured audits where possible. If an audit cannot run, mark that evidence unavailable and avoid awarding a score based on assumptions. Keep evaluator notes for reproducibility.
